# AES Safe Test (Proof of Concept)

**ВНИМАНИЕ:** Этот проект создан исключительно в **образовательных целях** для демонстрации работы симметричного шифрования (AES) и графического интерфейса на PyQt6.

## Что делает программа?
1. Создает папку `SAFE_TEST` на рабочем столе.
2. Шифрует файлы **ТОЛЬКО** внутри этой папки (алгоритм Fernet / AES).
3. Показывает заблокированный экран с требованием пароля.
4. При вводе правильного пароля (`1234`) — расшифровывает файлы обратно.

## Безопасность
Программа **физически не может** зашифровать системные файлы или файлы за пределами папки `SAFE_TEST`. В ней отключены функции автозапуска и блокировки системы. Код является безопасным Proof of Concept (PoC).
